# Status — community preparation, 29 October 2026

The first personal instance was reported working for reading and writing by its user. Automated tests use fictitious credentials. The OAuth flow was also reproduced in Chromium with a simulated callback.

Distribution to others is prepared in this branch and still needs testing on a new instance. No public release, shared service or spending has been undertaken. The existing personal instance and plugin are not replaced.
