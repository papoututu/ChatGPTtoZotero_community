# Protocole pour les premiers testeurs

Objectif : vérifier si un chercheur non informaticien peut suivre le guide sans intervention sur les fichiers du code.

Recruter ouvertement des volontaires, notamment sur Reddit, chacun sur **sa propre instance**. Ne pas les inviter comme collaborateurs GitHub. Un dépôt public leur donne accès au guide sans droit d’écriture. Voir [le protocole de bêta ouverte](open-beta.fr.md). Utiliser une bibliothèque ou quelques références dont le contenu peut être transmis à ChatGPT. Le mainteneur ne collecte ni clé ni mot de passe.

| Étape              | Réussite attendue                                     | À noter                                                   |
| ------------------ | ----------------------------------------------------- | --------------------------------------------------------- |
| Installation       | Service Render Live avec les quatre champs compris    | Temps approximatif, termes ou écrans bloquants            |
| Authentification   | Un clic après le mot de passe ramène dans ChatGPT     | Navigateur/application et message d’erreur s’il y en a un |
| Lecture            | Collections ou notice connue retrouvées               | Concordance avec Zotero Web                               |
| Dédoublonnage      | Référence connue reconnue sans création               | DOI puis titre/auteur, ambiguïtés conservées              |
| Écriture contrôlée | Une seule note ajoutée puis relue                     | Aucune autre modification                                 |
| Usage courant      | Tags/collection ajoutés sans retrait des anciens      | Tester seulement sur des notices autorisées               |
| Mobilité           | Même lecture possible depuis l’application habituelle | Produit, système, possibilité de sélectionner le MCP      |
| Reconnexion        | Expiration gérée et nouvelle connexion réussie        | Difficulté et nombre de manipulations                     |

Ne pas annoncer une compatibilité « tous mobiles » sur la base du seul navigateur du développeur. Un échec de disponibilité des MCP dans un produit n’est pas résolu en publiant simplement le code.

## Retour à envoyer

- Ton niveau d’aisance technique : débutant / intermédiaire / avancé.
- Étape atteinte et résultat attendu/obtenu.
- Application ChatGPT, navigateur et système.
- Texte exact de l’erreur, après retrait des informations personnelles.
- Manipulations que tu aurais préféré éviter.

Le test est réussi quand la personne termine lecture + une écriture contrôlée, comprend comment désactiver les écritures et sait révoquer la clé. La note de validation restera dans sa bibliothèque : aucun outil de suppression ne sera ajouté pour ce test.
