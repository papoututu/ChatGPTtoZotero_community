# Settings in plain language

Examples are fictitious. Never use a value copied from an example as a key or secret.

| Setting | Must you enter it? | Explanation and location |
|---|---|---|
| `ZOTERO_USER_ID` | Yes | Number beside “User ID” in Zotero → Settings → Keys. Fictitious example: `1234567`. |
| `ZOTERO_API_KEY` | Yes, secret | Key created for this server, stored only in Render. Replace it if the previous one is revoked in Zotero. |
| `OWNER_PASSWORD` | Yes, secret | Password of at least 20 characters used only on the server's consent page. It is not your Zotero password. |
| `WRITE_ENABLED` | Yes in the Blueprint | Exact text `false` for read-only; `true` to allow the five write tools. Render may mask it as a secret. Surrounding whitespace is tolerated, but quotation marks and “yes/no” are not. |
| `AUTH_SIGNING_SECRET` | No | Generated by Render. Signs MCP authorizations. At least 32 characters; changing it invalidates existing connections. |
| `PUBLIC_URL` | Not on Render | Detected from `RENDER_EXTERNAL_URL`. For another host: HTTPS origin, without `/mcp`. |
| `PORT` | Not on Render | Provided by the host; defaults to `8787` locally. |
| `OAUTH_CLIENT_ID` | No | Defaults to `zotero-cloud-personal`. This name is not secret and can be identical on independent servers. |
| `OAUTH_REDIRECT_URI` | Only if ChatGPT requires it | Exact callback displayed for the connection. Default: `https://chatgpt.com/connector_platform_oauth_redirect`. |
| `NODE_VERSION` | No | Node.js version fixed in the deployment. |

The server uses one personal library per installation. Do not enter someone else's key to “share” your server with them. Each tester creates their own instance.

## What is automated

HTTPS, build/start commands, the signing secret, Render address discovery and OAuth metadata. A configuration error gives the **setting's name** and expected format without displaying its value.

## What the developer cannot fill in for you

Your ID, Zotero key, password and decision to enable writes. These details and decisions belong to your account.
