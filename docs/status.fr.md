# État — préparation communautaire du 29 octobre 2026

La première instance personnelle a été déclarée fonctionnelle en lecture et en écriture par son utilisateur. Les tests automatisés utilisent des identifiants fictifs. Le parcours OAuth a aussi été reproduit dans Chromium avec un callback simulé.

La distribution pour d’autres personnes est préparée dans cette branche : elle reste à tester sur une instance neuve. Aucune publication publique, aucun service partagé et aucune dépense engagés. L’instance et le plugin personnels existants ne sont pas remplacés.

Les prochaines vérifications sont dans [publication.md](publication.fr.md) et le [protocole premier testeur](first-testers.fr.md). La publication dans le répertoire public ChatGPT serait une phase distincte.
