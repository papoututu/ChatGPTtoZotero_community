# Controlled live validation

Follow the read-then-write stages in the [installation guide](installation.md). Start with an existing unique item identified by a known DOI. Present the validation note text before creating it, then check exactly one child note and no other change.

For references extracted from a transcript, read the source before proposing additions. Distinguish verified titles from author-only mentions, examine approximate spoken titles, search for duplicates and preserve documented reasons in child notes. Never invent a recommendation or a reason to read a source.
